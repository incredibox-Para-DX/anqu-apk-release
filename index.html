MOD DOC

制作 MOD 有两种方式：① 使用游戏内的「MOD EDITOR」可视化制作，最简单；② 按本指南手动打包 zip。下方为手动方式说明。

推荐：在侧栏「MODS」下方点「MOD EDITOR」，可填表格、上传图片/音效、实时预览并一键生成安装，无需手写代码。

第一步：下载官方模板

若失效请到交流群反馈

第二步：制作你的模组

解压模板 → 替换 content/ 里的图片 → 用记事本修改 mod.json → 重新打包为 zip（选中里面的文件打包，不要连外层文件夹）。

你的模组.zip
├─ mod.json          模组定义（名称/作者/类型/内容列表）
├─ thumb.png         列表缩略图 300x180
├─ avatar.png        作者头像 128x128
├─ screen-1.png      详情展示图（可选，最多 3 张）
└─ content/
   ├─ items/         （物品类）物品图片
   ├─ music/         （音乐类）音频 mp3 等
   └─ backgrounds/   （背景类）图片或视频
字段速查
  • 物品：name 名称 / desc 描述 / width 1~5 / height 1~6 / value 最高 4,000,000 / rarity purple|gold|orange|red / weight 爆率权重(可选) / sound 音效(可选) / image 图片
  • 音乐：title 标题 / artist 作者(可选) / file 音频 / cover 封面(可选)
  • 背景：name 名称 / file 图片或视频
物品类 mod.json 写法 
{
  "name": "我的物品模组",
  "author": "你的名字",
  "version": "1.0.0",
  "type": "item",
  "desc": "一句话简介",
  "items": [
    { "name": "物品名", "width": 1, "height": 1,
      "value": 50000, "rarity": "purple",
      "image": "content/items/物品图.png",
      "desc": "物品描述" }
  ]
}
音乐类 mod.json 写法 
{
  "name": "我的音乐模组", "author": "你的名字",
  "version": "1.0.0", "type": "music", "desc": "简介",
  "tracks": [
    { "title": "歌名", "artist": "歌手",
      "file": "content/music/歌.mp3",
      "cover": "content/music/封面.png" }
  ]
}
背景类 mod.json 写法 
{
  "name": "我的背景模组", "author": "你的名字",
  "version": "1.0.0", "type": "background", "desc": "简介",
  "backgrounds": [
    { "name": "背景名", "file": "content/backgrounds/背景.png" }
  ]
}

上传须知（违反无法通过审核）

  • 物品 value 上限 4,000,000
  • 物品 rarity 只能是 purple / gold / orange / red；width 1~5、height 1~6
  • thumb.png、avatar.png 必填；screen 最多 3 张
  • 名称与描述不得包含违规内容
  • 可选：物品支持音效字段 sound（mp3/wav/ogg）
