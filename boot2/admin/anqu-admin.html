资源仓库总览

说明

· 清单读取走 jsDelivr 公共 CDN（无需 Token）；写入 / 上传资源需要 GitHub Token（Fine-grained PAT，权限 Contents: Read and write）。
· 客户端启动时会各自读取 manifest.json，保存后玩家侧最长约 12 小时才会拿到新清单；面板里每个资源包都提供 刷新 CDN 按钮（jsDelivr purge），点一下可立即生效。
· 小游戏资源包（MiniGame/）用于水果忍者，删除文件后请在客户端「资源下载」里重新下载；已安装的旧包不会被远程删除。
· 玩家侧数据（累计价值、已解锁背景、本地缓存）保存在手机 localStorage / IndexedDB 里，没有后端接口可供远程读取或修改。若要远程查看/修改玩家数据，需要后续给 App 增加服务端。
