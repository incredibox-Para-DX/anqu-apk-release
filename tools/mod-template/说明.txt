========================================
 暗区保险模拟 · Mod 制作说明（物品类）
========================================

一、模组里有什么
----------------------------------------
mod.json        模组的"大脑"，所有内容都在这里定义（必填）
thumb.png       列表缩略图，建议 360x202（必填）
avatar.png      作者头像，建议 128x128（必填）
screen-1~3.png  详情页展示图，最多 3 张（可选）
content/        内容文件目录：物品图片/音效放 content/items/

二、mod.json 字段说明（物品类）
----------------------------------------
name    模组名称（必填，≤20 字）
author  作者名（必填，≤16 字）
version 版本号（必填，如 1.0.0）
type    模组类型（必填，物品类固定填 "item"）
desc    模组简介（必填，≤60 字）

items   物品数组（最多 30 个），每个物品：
  name    物品名（≤12 字）
  width   占格宽（1~5）
  height  占格高（1~6）
  value   物品价值（1~4000000）
  rarity  稀有度：purple / gold / orange / red
  image   图片路径，相对 zip 根目录，如 content/items/xx.png
  sound   音效路径（可选），mp3/wav/ogg，如 content/items/xx.wav
  desc    物品描述（≤60 字）

三、硬性规则（违反无法通过审核）
----------------------------------------
1. value 上限 4,000,000
2. 单张图片请控制在 500KB 内（更省流量，非强制）
3. 图片请用 PNG / JPG，深色背景效果最佳
4. thumb.png、avatar.png 必填
5. 名称与描述不得含违规内容

四、制作步骤（三步）
----------------------------------------
1. 解压本模板，把 content/items/ 里的示例图片换成你自己的
2. 用记事本（或任意文本编辑器）打开 mod.json，照着示例改：
   - 改 name / author / desc
   - 改每个物品的属性，图片路径对应你放的文件
   - 增删物品：复制一段 { ... } 改内容即可（注意逗号）
3. 重新打包成 zip（注意：是选中"里面的文件"打包，
   不要把外层文件夹打进去，保证打开 zip 第一眼就是 mod.json）
