1. 确认 Key 类型
必须使用 service_role key（在 Supabase 后台 → Project Settings → API → service_role）。
anon key 只能读取，不能删除数据。

2. 用本地服务器打开（解决 CORS）
如果直接双击 HTML 文件（file:// 协议）打开，可能被浏览器 CORS 策略拦截。
请在该文件所在目录启动本地服务器：
python3 -m http.server 8080
然后浏览器访问 http://localhost:8080/leaderboard-admin.html

3. 检查 RLS 策略
登录 Supabase → Table Editor → ab_leaderboard → 右侧 RLS 策略。
service_role key 默认绕过 RLS，如仍报错可临时关闭 RLS 测试。

4. 查看具体错误
上方表格区域会显示 Supabase 返回的完整错误信息，请根据提示排查。
